Contribute a solution

Add a reusable solution, correct a record, or move a record so that you host it yourself.

Before you start

A solution can be included if it is intended for reuse by more than one public body, has an owner who accepts responsibility for the record, and can be described without personal, confidential or security-sensitive information. Read the full inclusion test.

Describe the solution you offer, not a code repository. A repository on its own is not a common solution; if your solution has code, list it as one of the solution's codebases, each with its own publiccode.yml.

You will need: the solution's name and purpose, the owning organisation, a role-based contact (not a named person), its status and terms of use, the service address and your page describing it, and how another organisation can adopt it.

Choose how to contribute

Use the form

Answer questions in your browser. The form checks your answers and builds a solution.yml for you to submit by GitHub or email.

Add a solution

Host it yourself

Publish a solution.yml in your own repository, beside any publiccode.yml. Once registered, your changes are published automatically after validation.

How to host it

Open a pull request

If you use GitHub, add a record file to the register's repository. Checks run automatically.

Contributing guide

Email us

Send a downloaded solution.yml, or ask us to help you write one. You do not need a GitHub account.

What happens next

  1. Your submission is checked against the schema and rules. You will see any problems straight away on GitHub or in the form.
  2. A maintainer checks it meets the inclusion test. If you are not from the owning organisation, the owner is asked to confirm it.
  3. Once merged, the record appears on the site, usually within a few minutes.

Correct or remove a record

Use "Suggest a correction" or "Report a problem with this page" on the record, or email us. During the demonstrator, records about real organisations are removed on request.

GitHub issues and pull requests are public. By submitting, you agree your submission may be published under the Open Government Licence v3.0.
