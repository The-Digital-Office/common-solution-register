Data and API

Everything on this site is generated from one set of records, and published as open data under the Open Government Licence v3.0.

Warning
The API is version 0 and may change without notice. Web addresses may change if the demonstrator moves. Use record IDs, not URLs, as identifiers. Every record includes record_status, so you can exclude demonstration and example records.

Download everything

register.json

JSON, [size]. Every record with derived fields.

register.csv

CSV, UTF-8, [size]. One row per record. Nested fields use dotted column names.

API

Static JSON files. No key or registration is needed.

URLReturns
api/v0/index.jsonGeneration time, schema and taxonomy versions, licence, links
api/v0/assets.jsonAll records
api/v0/assets/csr-0001.jsonOne record
api/v0/taxonomy/capabilities.jsonTaxonomy terms with definitions (also sectors and service areas)
api/v0/schema/asset.schema.jsonThe JSON Schema
api/v0/harvest-state.jsonEach owner-hosted source: last harvest, state, content hash
