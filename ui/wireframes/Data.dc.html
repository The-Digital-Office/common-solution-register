Data and API

Everything on this site is generated from one set of records, and published as open data under the Open Government Licence v3.0.

Warning
The API is version 0 and may change without notice. Web addresses may change if the demonstrator moves. Use record IDs, not URLs, as identifiers. Every record includes record_status, so you can exclude demonstration and example records.

Download everything

register.json

JSON, [size]. Every record with derived fields.

register.csv

CSV, UTF-8, [size]. One row per record. Nested fields use dotted column names.

API

Static JSON files. No key or registration is needed.

URLReturns
api/v0/index.jsonGeneration time, schema and taxonomy versions, licence, links
api/v0/assets.jsonAll records
api/v0/assets/csr-0001.jsonOne record
api/v0/taxonomy/capabilities.jsonTaxonomy terms with definitions (also sectors and service areas)
api/v0/taxonomy/capabilities.ttlThe same taxonomy in SKOS, the W3C standard for vocabularies, as Turtle (also sectors and service areas). Each term's address is its page on this site.
api/v0/schema/asset.schema.jsonThe JSON Schema
api/v0/harvest-state.jsonEach owner-hosted source: last harvest, state, content hash
api/v0/metadata.jsonA description of this data and the API, for data catalogues (see Metadata)

Metadata

The register's open data is described in api/v0/metadata.json using the UK Cross-Government Metadata Exchange Model. This is the UK government's standard for describing data assets, based on the W3C's Data Catalog Vocabulary (DCAT). Data catalogues, such as the Cross-Government Data Marketplace, can read it to list this data.

The file describes:

  • the dataset: every record in the register, its publisher, licence and contact, and that it is updated daily
  • two distributions: register.json and register.csv, with their format and size
  • a data service: this API, version 0, with the status Alpha

Both api/v0/index.json and data/register.json link to it.

The fields and their values follow the model, with one exception. The model takes the publisher and creator from its list of GOV.UK organisations, which does not include [host organisation], so the organisation is named in full instead.

The metadata describes the data as a whole. Records are not described one by one: each record already follows the register's own schema.
