How harvesting works

  1. An owner publishes their solution.yml and asks for it to be registered. Registration is a reviewed change.
  2. Every day, and on request, the register fetches each registered address over HTTPS.
  3. It checks the record ID and owner match the registration, then validates the file and any linked publiccode.yml.
  4. Valid files are published straight away. Owners do not need a maintainer to approve their edits.
  5. If a source fails or disappears, the last valid version stays and is flagged. A maintainer decides whether to withdraw it after 7 days.

Only registered addresses are fetched. The register does not search for unregistered files.
