Validate a solution.yml

Check a descriptor against the register's schema and rules before you submit or host it. Your file is checked in your browser and is not sent anywhere.

This page needs JavaScript. Without it, run csr validate path/to/solution.yml from the command line, or use the workflow below.

Works where the host allows cross-site requests, as raw GitHub files do. Otherwise, paste the file.

Validate automatically in your own repository

If you host your solution.yml on GitHub, add this workflow to check it, and any publiccode.yml, on every pull request.

jobs:
  solution:
    uses: {{ config.repository_url | replace("https://github.com/", "") }}/.github/workflows/validate-solution.yml@v0

Or run csr validate path/to/solution.yml from the command line.
