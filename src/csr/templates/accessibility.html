Accessibility statement

This statement applies to the Common Solution Register demonstrator. We want as many people as possible to be able to use it. You should be able to:

  • change colours, contrast levels and fonts
  • zoom in up to 400% without the text spilling off the screen
  • navigate the whole site using just a keyboard
  • use the site with a screen reader

The site is built with the Scottish Government Design System, which is designed to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

How accessible this site is

{{ pending("accessibility_assessment", "the result of the self-assessment and manual testing") }} We know of these limitations:

  • The Add a solution and Validate pages need JavaScript. Every other page works without it. Without JavaScript you can still submit a solution by email or GitHub issue.
  • Code examples and YAML files are shown as preformatted text, which may need horizontal scrolling on small screens.

Feedback and contact information

If you find a problem or need information in a different format, contact {{ mailbox() }}. We will reply within {{ pending("accessibility_reply_days", "number of") }} working days.

Enforcement procedure

The Equality and Human Rights Commission is responsible for enforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018. If you are not happy with how we respond to your complaint, contact the Equality Advisory and Support Service.

Technical information

This site is partially compliant with WCAG 2.2 AA, due to the limitations listed above.

How we tested this site

Automated testing with axe-core on every change, and a manual keyboard and screen-reader check on {{ pending("accessibility_tested_on", "date") }} before publication.
